# GoodFuel.Life React SPA

This project migrates the original static GoodFuel.Life landing page into a React single-page application powered by Vite. It includes product listings, cart and delivery logic, and WhatsApp flows for both one-time orders and subscriptions.

## Getting Started

```bash
npm install
npm run dev         # start local dev server
npm run build       # production build
npm run preview     # serve the production build locally
npm run lint        # run ESLint
```
